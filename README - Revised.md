# openai-chatkit-starter-app (Seif's fork) — plain-language README

## What this is
This is Seif's copy (a "fork") of **openai/openai-chatkit-starter-app**, OpenAI's starter code for putting a ChatKit chat window in your own website. (ChatKit is OpenAI's ready-made chat interface. Agent Builder is OpenAI's tool for designing AI assistants.)

## Who it's for
Developers who want a working example to build on before writing their own.

## What it does today
It contains two starter apps:
- `chatkit/`: you host and run the chat setup yourself.
- `managed-chatkit/`: OpenAI hosts the workflow (the assistant's steps) and your app connects to it.

**Seif's changes vs upstream:** none found. There are no commits by Seif.

## How to run it
Each folder has its own setup. Follow the README in `chatkit/` or `managed-chatkit/`. You will need your own OpenAI API key; never commit it to the repo. Exact commands: not yet confirmed here.
